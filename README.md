💀 The story
Westvale High has stood since 1931, home of the Pirates. Tonight a blood-red moon hangs over the school, and the students, teachers and even the cops on patrol have come back... hungry.
You are GozaPlayz. Red headband. Black hoodie. One revolver and $500 in your pocket.
Board up the windows. Buy your way through the halls. Crack open the Mystery Box. Drink the colas. And whatever you do, don't stop moving.
How many rounds can you survive?
---
⚡ Features
🧟 Endless rounds. Every wave is bigger, faster and tougher than the last. Walkers turn into runners, runners turn into sprinters.
🏫 A whole school to fight through. Seven areas: Front Lobby, Main Hallway, Classrooms, Cafeteria, Gymnasium, Science Wing and the Rooftop Overlook. Pay to open each door and push deeper.
🔫 10 wild weapons, each with its own special trick (see below).
🎁 The Mystery Box. $950 for a random gun. Feeling lucky?
🥤 3 Perk-A-Colas that change how you play.
💥 Power-ups dropped by the dead: Max Ammo, Insta-Kill and Nuke.
🪵 Barricades. Zombies tear the boards off the windows; hold the button to nail them back on (and earn cash while you do it).
🎨 Customize. Recolor every gun to one color of your choice with the hue slider, or keep their original looks.
💾 Save & Exit from the pause menu and come back later with Load Game.
📱 Built for phones: twin-stick touch controls, full screen, home-screen app, works with no internet.

🎮 Controls
📱 iPhone / iPad / Android
Hold the phone sideways (landscape).
Control	Action
Left thumb (left side of the screen)	Move
Right thumb (right side of the screen)	Aim and shoot
RELOAD	Reload
SWAP	Next gun
KNIFE	Quick knife slash
LUNGE	Sword dash (Dragonslayer Blade only)
USE	Buy, open doors, drink colas, rebuild boards (hold)
II (top middle)	Pause, Save & Exit

🧠 Survival tips
Spend early on doors. More room to run = more room to live.
Rebuild boards between rounds. Each one is free money and buys you time.
Aim for the head. Headshots deal extra damage and power the Ronin DMR.
Never get cornered. Run big loops around the lobby statue and the trophy cases.
Save Insta-Kill moments for when the horde is thickest.
Big purple Boomers explode. Keep your distance.

🚀 How to run it
Play it online
Open the game link in any modern browser: Safari, Chrome, Edge or Firefox.
Install it like an app on iPhone / iPad
Open the game link in Safari.
Tap Share ⬆️ → Add to Home Screen → Add.
Launch it from your home screen. It runs full screen, works offline after the first load and keeps your save.
Install on Android / PC
In Chrome or Edge, tap the Install icon in the address bar (or menu → Install app).
Run it on your own computer
Because of the offline service worker, use a tiny local server instead of double-clicking the file:
```bash
cd westvale-zombies
python3 -m http.server 8000
```
Then open http://localhost:8000.

🛠️ Host your own copy on GitHub Pages
Create a new public repository (for example `westvale-zombies`).
Add file → Upload files and drag in everything in this folder: `index.html`, `game.js`, `style.css`, `manifest.webmanifest`, `sw.js`, `.nojekyll`, `README.md` and the `icons` folder. Commit.
Settings → Pages → Deploy from a branch → branch main, folder / (root) → Save.
About a minute later it's live at `https://YOUR-NAME.github.io/westvale-zombies/`.
Updating: upload a new `game.js`, `index.html` and `sw.js`. Players get the update the next time they open the game (sometimes it takes one extra launch).
📁 Files
File	What it is

`icons/`	Home-screen and browser icons
